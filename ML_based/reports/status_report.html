알려진 이슈 (모두 수정 완료)

수정됨  CNN1D dilation padding 공식 오류 — models/cnn1d.py
padding = kernel_size // 2 → padding = (kernel_size - 1) * dilation // 2
dilation > 1 시 레이어마다 공간 차원 축소 → RuntimeError: Kernel size > input size
수정됨  CNN1D subprocess segfault (MPS/OMP) — orchestrator.py
DL 모델은 spawn subprocess 격리 + FORCE_CPU=1 + OMP_NUM_THREADS=1 필수.
PyTorch 2.x + Optuna trial loop → Apple Silicon SIGSEGV (exit -11)
수정됨  scalar_loader feature 매핑 누락 (10→20개) — loaders/scalar_loader.py
suffix strip 목록에 _contralateral 누락 + exact match → prefix match 필요.
수정 후 top-30 중 20개 정상 선택. 확인 로그: [scalar_loader] eta2 feature select: N개
수정됨  Optuna stale study 재사용 — train/optimize.py
study name에 nf{feature_count} 포함 필수. 미포함 시 feature set 변경 후에도 이전 study 재사용 → 메트릭 고착.
확인 로그: [Optuna] {model} fold=N: nf={n}, 기존 0 trials
수정됨  raw cycle injured-side 고정 매핑 — features/extract_raw_cycles.py
기존 raw cycle 추출은 injured=Right, contralateral=Left로 해석될 수 있었다.
수정 후 data/ID.csv의 Injured leg를 사용하고 actual_leg, side_basis를 함께 저장한다.
