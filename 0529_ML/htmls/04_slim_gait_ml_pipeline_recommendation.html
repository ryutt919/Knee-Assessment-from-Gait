1. 핵심 결론

현재 데이터 규모에서 가장 타당한 1차 분석 단위는 피험자 1명 = 1개 샘플입니다. slim_gait는 995,144개 time point를 포함하지만 독립 표본은 79명뿐이므로, row/time point/cycle을 무작위로 나누면 같은 피험자의 보행 패턴이 train/test에 동시에 들어가는 누수가 생깁니다.

추천 운영 모델: features_scalar.csv 또는 slim_gait 재추출 scalar feature를 subject-level pivot으로 변환하고, slow/normal/fast별 값, fast-slow 변화량, fast-normal 변화량, 3속도 평균, 양측 비대칭 및 LSI를 포함한 뒤 RF/XGBoost/LightGBM/SVC-RBF를 nested CV로 평가합니다.

4. 추천 파이프라인

1. 원본 정리 slim_gait에서 subject, group, speed, trial, left/right foot contact, 9개 관절각 채널을 사용합니다.
2. cycle 추출 Heel-strike to heel-strike로 cycle을 만들고 trial/leg별 처음 2개와 마지막 2개 cycle은 제외합니다.
3. feature 생성 peak, min, ROM, IC angle, peak timing, 101pt waveform, variability(mean/std/CV/IQR)를 만듭니다.
4. subject pivot slow/normal/fast, fast-slow, fast-normal, mean, injured-contralateral, LSI를 피험자 1행으로 결합합니다.
5. nested CV subject 또는 paired identity 기준 split, train-fold impute/scale/select, OOF subject-level 평가를 수행합니다.

1차 입력 feature set

  • 핵심 sagittal kinematics: knee_flexion peak/ROM/IC angle/peak timing, hip_flexion ROM, ankle_dorsiflexion ROM 및 timing.
  • 양측성 지표: injured, contralateral, injured-contralateral asymmetry, LSI. 문헌 노트가 양측 분석 필요성을 명시합니다.
  • 속도 반응성: slow/normal/fast 절대값과 fast-slow, fast-normal delta. ACL gait asymmetry는 빠른 보행에서 더 드러날 수 있고, 속도 자체도 confounder입니다.
  • cycle variability: cycle별 scalar의 std, CV, IQR, p10, p90. 평균값만 쓰면 trial 내 안정성/불안정성 정보를 잃습니다.

모델 선택

  • PrimaryRandom Forest, XGBoost, LightGBM, tuned SVC-RBF. 소표본 고차원 tabular에서 강하고, SHAP/permutation으로 해석 가능합니다.
  • SecondaryFPCA 또는 PCA-on-waveform 뒤 subject-level ensemble. waveform 장점을 쓰되 79명 제한을 존중합니다.
  • Exploratory1D-CNN/Transformer는 cycle-level GroupKFold와 subject-level voting/mean probability aggregation이 전제될 때만 사용합니다.

6. 검증 설계

금지: slim_gait time point, stride row, cycle row를 무작위로 train/test split하면 안 됩니다. 행 수가 커 보여도 같은 피험자의 반복 측정이므로 성능이 과대평가됩니다.
  • Primary metric은 subject-level ROC-AUC, macro F1, balanced accuracy로 보고합니다.
  • ACLD와 ACLR이 같은 참가자의 종단 기록일 가능성을 고려해, 가능하면 subject_id 숫자 부분을 paired identity로 묶어 sensitivity analysis를 수행합니다.
  • imputation, scaling, feature selection, PCA/FPCA, augmentation은 모두 train fold 안에서만 fit합니다.
  • group, subject_id, file_name, trial_id, injured_leg 같은 식별자는 predictor에서 제외합니다.
  • cycle-level 모델은 cycle 예측을 낸 뒤 test fold 안에서 subject별 평균 확률로 집계해 최종 metric을 계산합니다.
  • SHAP 또는 permutation importance는 outer fold OOF 예측과 함께 요약하고, knee_flexion/hip_flexion/ankle_dorsiflexion 및 asymmetry가 상위에 오는지 확인합니다.

8. 최종 권고

이 프로젝트에서 "최적" 파이프라인은 cycle을 모델 샘플 수로 착각하지 않고, cycle 정보를 피험자 수준으로 요약해 쓰는 방식입니다. 따라서 운영 후보는 subject-level multi-speed scalar ensemble이고, cycle-level waveform은 성능 개선과 생체역학적 해석을 보강하는 보조 축으로 두는 것이 가장 방어 가능합니다.

slim_gait만으로 만들 수 있는 가장 강한 근거 변수는 knee_flexion, hip_flexion, ankle_dorsiflexion 중심의 sagittal kinematics, injured/contralateral asymmetry, LSI, speed response입니다. KEM/KFM/vGRF는 문헌상 중요하지만 현재 원본에는 직접 포함되어 있지 않으므로, 논문/보고서에서는 "직접 측정하지 못한 제한점"으로 명확히 두는 것이 맞습니다.
