# Bilateral waveform analysis of gait biomechanics presurgery to 12 months following ACL reconstruction compared to controls

#### 연구 목적

- ACLR 전 후 2,4,6,12 개월 시험 보행 생체역학을 양측 다리간 그리고 성별, 연령, BMI를 매칭한 HA 대조군과 비교

#### 결과

- 수술-비수술 다리, 수술-HA, 비수술-HA 간 stance phase 전반의 생체역학적 차이

#### 방법

- 실험 방법
    - 보행
    - 3D motion capture
    - force plate
- 데이터 전처리
    - recursive fourth‐order low‐pass Butterworth filter 10Hz
    - 101point 정규화
- 데이터 분석
    - t-test
    - Mann-Whitney U test
    - cohen’s d
    - functional mixed effect model

#### 레퍼런스할 수 있는 내용 (원문 발췌, 해당 부분 원문에서 레퍼런스한 논문 참고논문 표기 해야함 )

- intro 부분의 ACL 손상 심각성
- stance phase 전체 시점 분석 필요성

#### 생각해볼만한 내용

- ACL 부상 군의 환측-건측 비교와, ACL 부상 환측-HA 다리 비교간의 차이점.
단순히 ACL 부상군의 asymmetry는 평가 능력이 떨어진다? → 부상자의 건측도 생체역학적 문제가 발생하며 환측의 회복뿐만 아니라 건측의 악화가 asymmetry에 영향을 주기 때문

#### 이 연구에서 지적하는 선행연구들의 문제점

- 이산적 point에 집중됨

#### 이 연구에서 선행연구를 해결하는 방식

- stance phase 전체 생체역학을 비교함
